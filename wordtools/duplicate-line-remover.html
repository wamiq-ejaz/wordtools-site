When you need this

Merged contact lists, exported spreadsheets, keyword research, and copy-pasted email threads often end up with the same line repeated several times. This tool keeps the first occurrence of each line and removes the rest, preserving your original order.

Options explained

  • Case-sensitive match: when off (default), "Apple" and "apple" are treated as the same line. Turn it on to treat them as different.
  • Trim whitespace before comparing: ignores leading/trailing spaces when deciding if two lines match, so "cat" and " cat " count as duplicates.

Frequently asked questions

Does this sort my list alphabetically?
No — the original order is preserved. Only repeated lines are removed.
Which occurrence of a duplicate is kept?
The first one. Every later repeat of the same line is removed.
