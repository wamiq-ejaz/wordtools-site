About WordTools

A small set of text tools, built to load fast and respect your privacy.

WordTools is a free collection of browser-based text utilities — a word counter, character counter, case converter, whitespace cleaner, text reverser and duplicate line remover, with more tools planned. Every tool runs entirely in JavaScript on your own device: nothing you type or paste is ever uploaded, logged, or stored on a server.

Why we built this

Most "online tools" sites bury a simple feature under ads, pop-ups and unnecessary account sign-ups. We wanted something closer to a well-made pocket calculator: open the page, do the task, get the result, move on.

How the tools work

Each tool is plain HTML, CSS and JavaScript. There's no backend processing your text — counting, converting and formatting all happen locally in your browser the moment you type. You can read exactly how each tool works by viewing the page source.
